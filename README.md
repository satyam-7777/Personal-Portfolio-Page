## Project Overview

The goal of the project is to build a personal portfolio webpage that introduces the developer, displays technical skills, showcases completed projects, and provides different ways to get in touch.

The portfolio is organized into four main sections:

- About
- Technical Skills
- Projects
- Contact

The page also includes a fixed navigation bar and a footer containing copyright and project information.

## Technologies Used

- HTML5
- CSS3

## Running the Project Locally

Since this is a static HTML/CSS project, no backend or package installation is required.

### 1. Clone the repository

```bash
git clone <https://github.com/satyam-7777/Personal-Portfolio-Page>
```

### 2. Navigate into the project

```bash
cd personal-portfolio
```

### 3. Open the project

Open `index.html` directly in a browser.

Alternatively, you can use the **Live Server** extension in VS Code.
